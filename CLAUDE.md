## Python
- Always run Python via the project venv: `"f:\Spotter AI\venv\Scripts\python.exe"` (never the global `python` / `py`).
  - Bash: `"/f/Spotter AI/venv/Scripts/python.exe" manage.py test`
  - PowerShell: `& "f:\Spotter AI\venv\Scripts\python.exe" manage.py test`
- Quote every path; the folder name contains a space.
